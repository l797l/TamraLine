# 🚌 TamraLine

### منصة النقل الجامعي للطلاب

**TamraLine** هي منصة إلكترونية تهدف إلى تسهيل عملية العثور على وسائل النقل المناسبة لطلاب الجامعات، من خلال توفير معلومات واضحة ومنظمة حول خطوط النقل ومساعدة الطالب على الوصول إلى الخيار المناسب بطريقة سهلة وسريعة.

**تمرا لاين... طريقك الأسهل إلى الجامعة 🎓**

</div>

---

## 📌 فكرة المشروع

يواجه الكثير من طلاب الجامعات صعوبة في العثور على خط نقل مناسب لمكان سكنهم وموقع جامعتهم ومواعيد دوامهم.

في كثير من الأحيان يعتمد الطالب على سؤال زملائه أو البحث في مجموعات التواصل الاجتماعي للوصول إلى سائق أو خط مناسب، مما يجعل عملية البحث تستغرق وقتًا وجهدًا.

جاءت فكرة **TamraLine** لتوفير منصة تجمع هذه المعلومات في مكان واحد، وتساعد الطالب على:

* 🚌 العثور على خطوط النقل المناسبة.
* 📍 معرفة تفاصيل الخط ومساره.
* 📋 الوصول إلى معلومات النقل بطريقة منظمة.
* ⏱️ توفير الوقت والجهد في البحث.
* 🎓 تحسين تجربة التنقل اليومية إلى الجامعة.

---

## ✨ المميزات

### 🚌 البحث عن خطوط النقل

يساعد الطالب على العثور على خطوط النقل المناسبة بالقرب من منطقة سكنه وبما يتناسب مع موقع جامعته.

### ⏱️ توفير الوقت والجهد

بدلًا من البحث بين الطلاب والسائقين أو السؤال عن الخطوط المتوفرة، يستطيع الطالب الوصول إلى المعلومات التي يحتاجها بسهولة.

### 📍 معرفة تفاصيل الرحلة

يوفر الموقع معلومات تساعد الطالب على معرفة تفاصيل الخط ومساره والمعلومات المتعلقة بالرحلة.

### 🎓 تجربة مخصصة للطلاب

تم تصميم المنصة مع التركيز على احتياجات طلاب الجامعات وطريقة تنقلهم اليومية.

### 🤝 الربط بين الطلاب والسائقين

يسعى TamraLine إلى بناء حلقة وصل بين الطلاب وأصحاب خطوط النقل لتسهيل الوصول إلى الخط المناسب.

### 📋 تنظيم معلومات النقل

جمع معلومات خطوط النقل في مكان واحد بدلًا من الاعتماد على الطرق التقليدية في البحث.

## 🚀 تشغيل المشروع محليًا

### 1. تحميل المشروع

```bash
git clone https://github.com/l797l/TamraLine.git
```

### 2. الانتقال إلى مجلد المشروع

```bash
cd TamraLine
```

### 3. تثبيت الحزم

```bash
npm install
```

### 4. تشغيل المشروع في وضع التطوير

```bash
npm run dev
```

بعد تشغيل المشروع، افتح:

```text
http://localhost:3000
```
